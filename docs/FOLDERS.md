# Folders and labels

Outlook uses folders. Gmail uses labels with the same names, except `Important` is created as `Priority` because Gmail reserves the name Important.

| Name | What belongs there | Scheduled sort may file read mail here | Review may trash marketing here |
|---|---|---|---|
| Newsletters | Promotions and mailing lists | Yes | Yes, after successful opt-out |
| Finance Newsletters | Money marketing, not statements | Yes | Yes, after successful opt-out |
| Entertainment | Streaming, games, events | Yes | Yes, after successful opt-out |
| Updates | Gmail updates that matched no tighter folder | Yes, Gmail fallback only | No. Left for review |
| Finance | Statements, banks, bills, receipts | Yes, receipt and confirmed finance rules | No |
| Orders | Orders and shipments | Yes, order rules | No |
| Security | Sign-in and verification | Yes, security subject or sender rules | No |
| Important / Priority | Fraud alerts, account warnings that need a look | Yes, confirmed rules | No |
| Health | Clinics, insurance claims, care mail | Yes, confirmed rules | No |
| School | School and student-aid mail on a personal account | Yes, confirmed rules | No |
| Legal | Complaints, collections, adverse action | Yes, confirmed rules | No |
| GITHUB | GitHub and similar dev notices | Yes | No |
| Tech | Cloud and developer accounts | Yes | No |
| Personal | Mail from a person | Yes, Gmail personal fallback | No |
| Local | City and neighborhood notices | Yes | No |

A school mailbox is not one of these folders and is not connected.

Inbox is not a filing destination. Removing the inbox label, or moving out of Inbox, is how filed mail leaves the inbox. Unread mail is not removed from Inbox.
